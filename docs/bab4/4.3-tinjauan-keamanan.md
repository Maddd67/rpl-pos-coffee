## 4.3 Tinjauan Kode dan Keamanan

Tinjauan kode dan keamanan dilakukan melalui inspeksi manual, daftar periksa keamanan, serta pengujian kasus batas dan penyalahgunaan hak akses sebelum rilis[cite: 11, 18, 21]. Fokus tinjauan mencakup pengendalian akses berbasis peran (`pemilik` dan `kasir`), perlindungan `POST` terhadap CSRF, pembatasan percobaan login berulang, serta pemisahan rahasia melalui variabel lingkungan[cite: 14, 18, 21].

| ID Temuan | Aspek / Kategori | Risiko | Status | Rujukan Bukti / Commit |
| :--- | :--- | :--- | :--- | :--- |
| SEC-01 | Kontrol akses & otorisasi peran | Akses rute/aksi khusus pemilik oleh peran lain | Diperbaiki | `docs/temuan-keamanan.md`, `app.py` |
| SEC-02 | Perlindungan CSRF pada form `POST` | Pengiriman permintaan `POST` lintas situs tanpa token | Diperbaiki | `app.py`, `templates/*.html` |
| SEC-03 | Konfigurasi rahasia & cookie sesi | Kunci statis atau cookie rentan pada mode produksi | Diperbaiki | `app.py`, `.gitignore`, rilis `v1.0.0` |

Sebagai contoh perbaikan keamanan pada `app.py`, permintaan `POST` diperiksa menggunakan perbandingan token konstan (`secrets.compare_digest`) sebelum diproses oleh rute aplikasi:

```python
if request.method == "POST":
    dikirim = request.form.get("csrf_token", "").encode("utf-8")
    asli = session.get("csrf_token", "").encode("utf-8")
    if not asli or not secrets.compare_digest(dikirim, asli):
        abort(400)
