## 4.4 Pengujian

Pengujian sistem Edu Coffee menggabungkan perancangan test case black-box (partisi ekuivalen, analisis nilai batas, skenario pelanggaran, dan jalur normal), pengujian otomatis berbasis `pytest` pada basis data sementara, pengujian regresi cepat, serta rencana dan pelaksanaan User Acceptance Test (UAT)[cite: 11, 18, 21]. Seluruh pengujian otomatis dijalankan menggunakan basis data temporer agar basis data kerja tidak terganggu.

| Jenis / Kelompok Pengujian | Rujukan Artefak | Ringkasan Cakupan & Status |
| :--- | :--- | :--- |
| Test case black-box | `docs/pengujian/test-case.md` | ≥ 20 test case terpetakan ke KF (EP, BVA, Pelanggaran, Normal) |
| Uji otomatis `pytest` & regresi | `tests/test_*.py`, `tests/uji_cepat.py` | Menguji validasi, alur HTTP, peran/CSRF, dan kesiapan rilis |
| Laporan cacat & perbaikan | `docs/pengujian/laporan-cacat.md` | Cacat `D-01` s.d. `D-03` dicatat, diperbaiki, dan diuji regresi |
| Pelaksanaan UAT & SUS | `docs/uat/hasil_uat.md`, `docs/uat/hitung_sus.py` | Skenario UAT-1 s.d. UAT-5, skor SUS `[ISI]`, triase umpan balik `[ISI]` |

Temuan cacat selama pengujian (`D-01` terkait angka Unicode pada input angka, `D-02` terkait batas nilai angka besar, dan `D-03` terkait ketatnya format tanggal `TTTT-BB-HH`) diperbaiki melalui alur uji gagal → perbaikan → uji lulus dan dipertahankan sebagai uji regresi[cite: 11, 16, 21]. Hasil rinci skor SUS dan catatan triase klien merujuk langsung pada `docs/uat/hasil_uat.md`
