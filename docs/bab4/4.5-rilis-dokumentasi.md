## 4.5 Rilis dan Dokumentasi

Rilis pertama aplikasi Edu Coffee ditetapkan dengan versi **1.0.0** mengikuti kaidah Semantic Versioning (`MAJOR.MINOR.PATCH`), ditandai melalui tag Git beranotasi `v1.0.0` setelah seluruh pengujian lulus dan digabungkan ke cabang utama[cite: 18, 21]. Aplikasi dijalankan menggunakan server WSGI **Waitress** dengan variabel lingkungan `APP_ENV=production` dan `SECRET_KEY` acak, serta mendukung konfigurasi `TOKO_DB` dan `COOKIE_SECURE` sesuai topologi jaringan[cite: 18, 21].

| Artefak Rilis | Lokasi | Fungsi Utama |
| :--- | :--- | :--- |
| Nomor versi | `versi.py` | Menyimpan `VERSI = "1.0.0"` dan menampilkannya di kaki halaman |
| Cadangan basis data | `cadangkan.py` | Membuat salinan basis data berstempel waktu ke folder `cadangan/` |
| Catatan perubahan | `CHANGELOG.md` | Merekam daftar fitur, perbaikan, dan aspek keamanan versi `1.0.0` |
| Panduan instalasi & operasi | `README.md` | Panduan pemasangan, konfigurasi lingkungan, akun awal, dan pemulihan |
| Panduan pengguna | `docs/manual_pengguna.md` | Alur kerja harian untuk peran `pemilik` dan `kasir` beserta tabel masalah |

Prosedur pencadangan dijalankan melalui `python cadangkan.py` dan diuji pemulihannya dengan menyalin berkas cadangan kembali ke basis data target setelah layanan dihentikan[cite: 18, 21]. Keterbatasan rilis `1.0.0` (seperti pembatasan percobaan login yang masih berada di memori proses dan belum tersedianya modul laporan penjualan terperinci) dicatat secara terbuka untuk pertimbangan pengembangan berikutnya[cite: 18, 21].
